# MY FIT

개인 옷장 · 코디 추천 · 착장 기록을 제공하는 정적 웹 앱입니다.

공개 사이트: https://kjk02468-cloud.github.io/my-fit-wardrobe/

공개 옷장의 의류 10개와 상세 사진 38장을 모든 기기에서 자동으로 불러옵니다. 별도 로그인이나 백업 가져오기가 필요하지 않습니다. 공개 데이터는 `published-closet.json`과 그 파일이 가리키는 버전별 JSON에 저장하며, 공개하기로 승인한 의류 정보와 상품 사진만 포함합니다. 착장 기록은 포함하지 않습니다.

기기에서 직접 추가·수정한 의류와 착장 기록은 해당 브라우저 IndexedDB에 저장합니다. 이 변경 내용의 양방향 동기화는 제공하지 않습니다. 공개 품목을 삭제하면 해당 기기에서만 숨겨집니다. 공개 옷장 버전을 갱신하면 기기별 수정 내용을 유지하면서 새 공개 품목을 자동으로 불러옵니다. 읽어 온 공개 옷장은 캐시하여 네트워크 연결이 끊겨도 다시 볼 수 있습니다.

GitHub Pages에서 배포하며 Vercel 및 Supabase에 연결하지 않습니다. 코디 추천은 등록한 아이템 속성과 선택한 외출 조건을 비교하는 규칙 기반 방식입니다. 날씨 조회에만 Open-Meteo를 사용합니다.

참고 사진은 상품·컬렉션 자료이며 각 사진의 출처는 앱에서 확인할 수 있습니다. 사진 저작권은 각 권리자에게 있습니다. 이 저장소에는 개인 착장 기록, 주문 화면, 연락처, 비밀 키를 포함하지 않습니다. 공개 옷장에 포함된 이름·사이즈·상품 사진은 사이트 방문자가 볼 수 있습니다.

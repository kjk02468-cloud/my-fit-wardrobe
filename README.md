# MY FIT

개인 옷장 · 코디 추천 · 착장 기록을 제공하는 정적 웹 앱입니다.

공개 사이트: https://kjk02468-cloud.github.io/my-fit-wardrobe/

공개 보유품 **66개, 아이템 사진 191장, 향수 6개**를 모든 기기에서 자동으로 불러옵니다. 별도 로그인이나 백업 가져오기가 필요하지 않습니다. `published-closet.json`이 가리키는 네 개의 데이터 조각으로 구성되며, 신규 품목은 작은 JSON과 압축 WebP로 추가합니다. 기존 대용량 사진 JSON을 복제하지 않습니다.

## 옷장과 사진

33개 신규 대표 이미지를 제품 또는 사용자 실물 자료에 맞춰 AI로 정리했습니다. 니트 베스트는 STANDARD JOURNAL, 옅은 갈색 셔츠는 MICHIKO LONDON, 체크 셔츠는 브랜드 미상으로 반영했습니다. 보유 사이즈·소재·품번은 확인된 정보만 기록합니다. 노셀코지 프론트 트랙 버뮤다 데님팬츠는 정확한 사진을 확인하지 못해 흑청/L 정보만 등록하고 사진 준비 중으로 표시합니다.

AI 보정은 실제 제품·공식 원본과 구별하여 표시하며 상세 갤러리에서 출처와 원본을 비교할 수 있습니다. 셋업 상하의는 별도 품목입니다. 발렌시아가 × 언더아머 리버서블은 한 벌이며 데님 면과 바람막이 면을 각각 표시합니다. 사진에 함께 나온 다른 상품을 보유품에 자동 추가하지 않습니다.

옷장 상단은 옷·옷걸이·선반·그림자를 한 장면으로 연출한 AI 완성 사진입니다. 베이지·퍼플 전시와 블랙·카키 전시 두 장면을 준비했습니다. 실제 방이나 실시간 3D 모델은 아닙니다. 봉에 연결한 원목 옷걸이 8자리와 선반 5자리로 구성되며, 향수 선반의 두 자리는 작은 병을 같은 높이에 나란히 진열합니다. 각 표시점은 사진 속 보유품 상세와 연결되고, 모든 66개 품목은 아래 목록에서도 볼 수 있습니다.

‘대표 아이템 고르기’에서 13자리를 검색·분류로 선택하고, 드래그 또는 좌우 버튼으로 옮기며, 비우기·취소·기본 구성 복원이 가능합니다. 향수는 왼쪽·오른쪽을 독립적으로 교체합니다. 중복 선택은 두 자리를 교환하고 리버서블은 원하는 착용 면을 선택합니다. 기존 12자리 저장값은 유지합니다. 준비된 배치와 일치하면 완성 사진을 바로 표시합니다. 새 배치는 선택 목록으로 저장하고 직전 완성 사진을 유지하며, ‘완성 사진 요청 복사’로 이름·ID·착용 면을 복사해 채팅에서 제작을 요청할 수 있습니다. 요청 복사만으로 서버에 전송하거나 자동 제작하지 않습니다.

완성 사진 두 장은 WebP 합계 250KB 미만입니다. 방문 때 AI 생성이나 사진 합성을 하지 않습니다. 원본 사진과 공개 옷장 데이터는 변경하지 않습니다. 선택한 ID·착용 면·직전 완성 사진 ID만 현재 브라우저 localStorage에 저장하고 사진을 복제하지 않습니다. 선택 배치는 기기 간 동기화되거나 기존 옷장 백업에 포함되지 않습니다. 보유품 수정·삭제로 완성 사진의 정보가 오래되면 일치하는 장면으로 취급하지 않습니다.

## 계절별 코디 60개

`curated-looks.json`은 봄·가을 / 여름 / 겨울 각각 20개, 총 60개의 중복 없는 보유품 조합입니다. 계절을 먼저 선택하고 출근·약속, 데이트·저녁, 데일리, 스트리트 분위기로 좁힐 수 있습니다. 각 코디에는 개별 모델컷, 추천 이유, 입는 방법, 사용한 아이템, 선택 가능한 액세서리와 향수가 있습니다. 여름은 반팔과 저지, 롤업 셔츠·스카시 가디건의 실내·저녁 착장으로 구성했고, 겨울은 보유 울 코트와 니트·후디를 겹칩니다. 한파 장시간 야외용 추가 방한품을 보유한 것으로 표시하지 않습니다. 셔츠와 베스트 같은 두 겹 상의도 모두 표시합니다. 리버서블 양면은 별도 코디에 쓰되 동일 보유품 ID를 유지합니다.

모델컷은 사용자가 허용한 SNS 프로필을 참고한 모델과 보유품 사진으로 사전 제작한 AI 이미지이며 실제 착용 사진이 아닙니다. 접근 가능한 얼굴 원본이 저해상도여서 얼굴·핏·세부 로고가 실제와 다를 수 있습니다. 원본 얼굴 사진은 저장소에 넣지 않습니다. 기존 20개와 신규 40개 모델컷 모두 압축 WebP이며 합계 1MB 미만입니다. 방문 때 AI를 호출하지 않습니다.

`curated-look-engine.js`는 보유품 ID와 이름·브랜드·색·사진을 확인합니다. 핵심 보유품이 없으면 코디를 숨기고, 사용자가 사진이나 제품 정보를 수정하면 기존 모델컷을 재사용하지 않습니다. 이전의 AI 모델 코디 5개와 조건별 규칙 기반 추천 모드도 유지합니다. 선택한 날씨와 외출 조건은 조건별 추천 모드에 적용되며, 60개 컬렉션은 계절 선택과 분위기 필터로 탐색합니다.

착장 참고 라이브러리는 GQ, MR PORTER, Harrods, UNIQLO U, COS, Hypebeast의 확인한 착장 40개입니다. 출처 링크·사진 URL·종류·색·핏만 저장하고 새 참고 사진은 저장소나 백업에 복제하지 않습니다. 이는 모델 학습이 아닌 속성 비교입니다. 원격 사진이 열리지 않으면 출처 링크를 제공합니다.

## 저장과 운영

기기별 수정과 착장 기록은 브라우저 IndexedDB에 저장합니다. 양방향 동기화는 제공하지 않습니다. 공개 데이터 갱신 시 기기별 수정·삭제를 유지하고 새 품목을 추가합니다. 공개 옷장은 캐시하여 오프라인에서도 볼 수 있고, 백업은 WebP 사진과 AI 표시·설명을 포함합니다.

GitHub Pages 정적 배포만 사용합니다. Vercel·Supabase·STOCKTOON LITE에 연결하거나 설정을 변경하지 않으며 유료 모델 API, 데이터베이스, 자동 이미지 수집 작업을 추가하지 않았습니다. 날씨는 Open-Meteo에서 조회합니다.

저장소에는 주문 화면, 주소, 연락처, 개인 착장 기록, 비밀 키, 얼굴 원본을 포함하지 않습니다. 공개 옷장 정보와 AI 모델컷은 방문자 누구나 볼 수 있습니다. 원본 자료의 출처는 각 아이템 상세에 표시하며 사진 권리는 각 권리자에게 있습니다.

## 검증

- `node tests/wardrobe-and-references.cjs`: 공개 데이터 분할 로드, 캐시·오프라인 대체, 기기별 수정 보존, 사진 포함 백업, 리버서블 양면, 참고 조합 비교.
- `node tests/model-looks.cjs`: 기존 모델 코디 모드와 실제 보유품 연결, 변경된 아이템의 오래된 모델 사진 제외.
- `node tests/curated-wardrobe.cjs`: 중복 없는 60개와 계절별 20개, 여름·겨울 레이어링, 분위기 필터, 보유품만 사용, 양면·레이어링, 필수 아이템 삭제 및 수정, 사진 경로와 파일 용량 제한.
- `node tests/room-editor.cjs`: 13자리와 기존 12자리 설정 보존, 향수 두 자리의 독립 선택, 중복 없는 자리 교환, 리버서블 착용 면, 삭제·예시 품목 제외, 손상된 저장값, 사진 복제 없는 소형 저장.
- `node tests/room-scenes.cjs`: 완성 사진과 아이템·착용 면 연결, 준비되지 않은 배치 구분, 오래된 사진 배제, 향수 두 자리와 경량 장면.

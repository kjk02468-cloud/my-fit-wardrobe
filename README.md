# MY FIT

개인 옷장 · 코디 추천 · 착장 기록을 제공하는 정적 웹 앱입니다.

공개 사이트: https://kjk02468-cloud.github.io/my-fit-wardrobe/

공개 옷장의 의류 25개와 사진 106장을 모든 기기에서 자동으로 불러옵니다. 별도 로그인이나 백업 가져오기가 필요하지 않습니다. 공개 데이터는 `published-closet.json`과 그 파일이 가리키는 버전별 JSON에 저장하며, 공개하기로 승인한 의류 정보와 상품 사진만 포함합니다. 착장 기록은 포함하지 않습니다. 새 품목은 작은 JSON과 압축 WebP 파일로 추가하므로 기존 대용량 사진 JSON을 매번 복제하지 않습니다.

기기에서 직접 추가·수정한 의류와 착장 기록은 해당 브라우저 IndexedDB에 저장합니다. 이 변경 내용의 양방향 동기화는 제공하지 않습니다. 공개 품목을 삭제하면 해당 기기에서만 숨겨집니다. 공개 옷장 버전을 갱신하면 기기별 수정 내용을 유지하면서 새 공개 품목을 자동으로 불러옵니다. 읽어 온 공개 옷장은 캐시하여 네트워크 연결이 끊겨도 다시 볼 수 있습니다.

25개 대표 사진과 리버서블 재킷의 반대 면, 총 26장은 원본을 기반으로 배경·주름·조명을 정리한 AI 보정 이미지입니다. 제품명·색·형태·소재·로고를 원본과 대조하고, 화면에 AI 보정을 표시합니다. 실제 제품의 세부 특징은 상세 갤러리의 원본으로 비교할 수 있습니다. 원본 사진 80장과 출처를 함께 보관합니다. 기존 기기에 같은 원본 대표 사진이 저장되어 있으면 공개 보정본으로 표시하되, 직접 교체한 대표 사진과 기기별 정보 수정은 유지합니다. 백업은 새 WebP 파일도 포함하는 독립 파일이며 AI 보정 표시와 사진별 설명을 유지합니다.

2026-11-02 추가 품목은 우영미 블랙 투 버튼 블레이저, 헨리코튼 몰스킨 블레이저 다크 그레이, 유어너스 블렌디드 데미지 벌룬 데님, 헤코멘즈 롱 와이드 브라운 데님, 사용자 사진의 브랜드 미상 흑청 와이드 데님, 발렌시아가 × 언더아머 리버서블 재킷입니다. 리버서블은 한 벌로 등록하고 데님 면과 바람막이 면을 각각 AI 보정본과 원본으로 보여줍니다. 번개장터와 추가로 받은 후루츠패밀리 자료를 함께 대조했으며, 판매자 사진을 공식 이미지로 표시하지 않습니다. 사진만 있는 데님의 브랜드·품번은 추정하지 않습니다.

앞으로 링크로 등록할 때도 공식 또는 이에 준하는 상품 자료를 먼저 확인하고, 검색 사진을 그대로 대표 사진으로 넣지 말고 내장 imagegen으로 새 상품처럼 정리합니다. 원본은 상세 사진에 남기고 AI 보정을 공식 원본으로 표시하지 않습니다. 품번·시즌·보유 사이즈를 추정해서 채우지 않습니다. 셋업도 요청에 따라 재킷과 팬츠를 각각 별도 품목으로 등록하며, 사진에 함께 나온 다른 옷을 보유품으로 자동 추가하지 않습니다.

GitHub Pages에서 배포하며 Vercel 및 Supabase에 연결하지 않습니다. 코디 추천은 등록한 아이템 속성과 선택한 외출 조건을 비교하는 규칙 기반 방식입니다. 날씨 조회에만 Open-Meteo를 사용합니다.

착장 참고는 GQ, MR PORTER, Harrods, UNIQLO U, COS, Hypebeast의 확인한 착장 40개를 이용합니다. `style-references.json`에는 출처 링크·사진 URL·옷 종류·색·관찰 가능한 핏만 저장합니다(약 24KB, 최대 96KB/80개). 새 참고 사진은 저장소·옷장 백업·IndexedDB에 복제하지 않고 화면에 표시할 때 원 출처에서 불러옵니다. 브라우저의 일반 이미지 캐시는 사용할 수 있습니다. 이미지를 읽지 못하면 출처 링크로 안내합니다. 이전의 소수 로컬 참고 사진은 목록을 읽을 수 없을 때만 대체 자료로 사용합니다.

이는 모델 학습이나 실시간 이미지 인식이 아닌 출처 기반의 속성 비교입니다. 보유 옷 조합의 아우터·상의·하의·신발을 함께 비교하고, 종류와 색이 가까운 구성 2개 이상일 때 참고 자료를 제시합니다. 등록 이름에서 확인되는 핏만 사용하며 사진 속 다른 옷을 보유품으로 추가하지 않습니다. 추천 점수에 참고 조합 유사도를 최대 6점 반영하고, 가능한 한 세 코디의 첫 사진이 중복되지 않도록 선택합니다. 비슷한 부분과 다른 부분, 부분 착장 여부, 원 출처를 표시하며 다른 참고 사진도 넘겨볼 수 있습니다. 유료 모델/API 호출과 별도 데이터베이스를 추가하지 않았습니다.

검증: `node tests/wardrobe-and-references.cjs` — 공개 데이터 분할 로드·캐시·오프라인 대체·기기별 수정 보존·사진 포함 백업·리버서블 양면 표시·전체 조합 비교·사진 다양성·참고 목록 장애 대체를 확인합니다.

참고 사진은 상품·컬렉션 자료이며 각 사진의 출처는 앱에서 확인할 수 있습니다. 사진 저작권은 각 권리자에게 있습니다. 이 저장소에는 개인 착장 기록, 주문 화면, 연락처, 비밀 키를 포함하지 않습니다. 공개 옷장에 포함된 이름·사이즈·상품 사진은 사이트 방문자가 볼 수 있습니다.
